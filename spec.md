# Specification

## Summary
**Goal:** Build a promotional and booking website for "Omm Vedic Numerology" with a mystical spiritual theme, showcasing four core services and allowing users to submit booking requests.

**Planned changes:**
- Create a homepage with a hero section displaying the brand name "Omm Vedic Numerology" on a mystical cosmic background, plus a navigation bar linking to Services and Booking sections
- Add a Services & Pricing section with four service cards (Tarot Card Reading, Numerology, Vastu, Pronology), each showing a description, icon illustration, price of ₹400, and a "Book Now" button
- Build a booking form section with dropdowns for service type (Tarot Card Reading, Numerology, Vastu, Pronology) and booking category (Appointment, Home Tour, Name Change), plus inputs for full name, phone number, preferred date, and optional message — with ₹400 price displayed prominently
- Show a success confirmation message after a booking is submitted
- Apply a cohesive mystical theme using deep navy/dark backgrounds with gold and amber accents, elegant display typography for headings, and celestial/mandala decorative elements
- Backend data model and functions to store and retrieve bookings (fields: service type, booking category, customer name, phone number, preferred date, optional message, status)

**User-visible outcome:** Visitors can learn about Omm Vedic Numerology's four services, see the ₹400 pricing, and submit a booking request for an Appointment, Home Tour, or Name Change — receiving a confirmation message on success.
